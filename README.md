# Personal Portfolio — Q1 (GitHub Pages)

A responsive, single-page portfolio prepared for Question 1 of CS-117 Assignment 2. It uses plain HTML, CSS, and JavaScript, so no build tools or dependencies are required.

## Before publishing — personalize the site

Open `index.html` and replace every example/placeholder with your real information:

1. `Your Name` / `[Your Full Name]`
2. Degree, semester, and university
3. The About paragraph (keep it between 80 and 150 words)
4. Skills: remove any tool you cannot actually use
5. Project titles and descriptions: replace the three examples with real course projects/labs you completed
6. GitHub username, LinkedIn profile, and professional email
7. Change the `YN` initials in the header and replace `assets/avatar.svg` with your own photo/avatar if desired.

Do not publish your phone number, home address, CMS ID, passwords, or other private information.

## Preview locally

Open `index.html` in a browser. You do not need Node.js, npm, or a server.

## Publish using GitHub Pages

1. Create a **public** GitHub repository named exactly `YOUR-GITHUB-USERNAME.github.io` (replace with your GitHub username).
2. Upload all files and folders in this repository to the root of that repository. Keep `index.html` at the root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. Visit `https://YOUR-GITHUB-USERNAME.github.io`.
7. Test every link and check the site on a phone-sized screen. Take a screenshot showing the live URL and date/time for your assignment evidence.
